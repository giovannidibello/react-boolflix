# 🎬 Movie Finder - React App

Un'applicazione di ricerca di film e serie TV che utilizza l'API di [The Movie Database (TMDb)](https://www.themoviedb.org/).  
L'app consente agli utenti di cercare film e serie TV, visualizzare i risultati e navigare tra le informazioni usando React, Axios e React Router.

## 🖥️ Progetto realizzato con

- React.js
- Axios
- React Router
- [The Movie Database (TMDb) API](https://www.themoviedb.org/)
- Visual Studio Code

## 🚀 Come visualizzare il progetto

1. Clona il repository o scarica la cartella ZIP.
2. Esegui `npm install` per installare le dipendenze.
3. Avvia l'app con il comando `npm dev`.
4. Apri il browser all'indirizzo `http://localhost:5173/` per vedere l'app in esecuzione.

> ⚠️ L'applicazione utilizza l'API di TMDb per cercare film e serie TV. Per utilizzare l'API, è necessaria una chiave API valida, che puoi ottenere [qui](https://www.themoviedb.org/settings/api).

## 🎯 Obiettivi didattici

- Utilizzare React Router per la gestione delle rotte.
- Creare un contesto globale (`GlobalContext`) per gestire i dati tra i componenti.
- Gestire le chiamate API con Axios.
- Visualizzare e gestire i risultati delle ricerche per film e serie TV.
- Creare un layout responsivo con React.
